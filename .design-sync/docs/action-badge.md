Recommendation pill keyed to the four farmer actions — `haul` (amber, truck),
`hold` (prairie, lock), `price` (canola, dollar), `watch` (wheat, eye). Each
carries an icon + glow. `size` is `lg` (default) or `sm`.

## Examples

```tsx
<ActionBadge action="haul" />
<ActionBadge action="hold" size="sm" />
```
