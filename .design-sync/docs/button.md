Primary action control. Use `variant` for emphasis — `default` for the main
action, `secondary`/`outline`/`ghost` for lower emphasis, `destructive` for
irreversible actions, `link` for inline navigation. Use `size` for density
(`sm`, `default`, `lg`, plus icon-only `icon`/`icon-sm`/`icon-lg`). Set
`asChild` to apply the styling to a child element such as a Next.js `<Link>`.

## Examples

```tsx
<Button>Haul grain</Button>
<Button variant="outline">View thesis</Button>
<Button size="sm" variant="ghost">Dismiss</Button>
```
